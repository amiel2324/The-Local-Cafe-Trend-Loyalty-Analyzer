The Local Cafe Trend & Loyalty Analyzer

Catbalogan City Branch • Classroom Defense Presentation Deck

Project Overview

A lightweight, single-screen Business Intelligence prototype designed for local food and beverage cafes in Catbalogan City, Samar.

  • Core Objective: Replace slow paper receipts and manual calculations with real-time sales analytics.
  • Technology Stack: Pure Vanilla JavaScript, HTML5 Canvas API, and CSS3.
  • Key Feature: Operates entirely in browser memory using functional array methods (.push, .reduce, .filter).

Background & Problem Statement

The Operational Challenges Facing Catbalogan Cafe Operators

Traditional Cafe Management

  • Manual sales tracking via paper receipts or basic calculators.
  • No visibility into shift-by-shift sales trends or customer activity.
  • Difficulty determining stock needs between drinks, pastries, and meals.

The BI Information Gap

  • Which operational shift is our peak revenue driver?
  • What menu categories sell best in the morning vs. evening?
  • Are local customers transitioning from Cash to GCash digital payments?

Project Scope & Technical Solution

Boundaries and Architecture of the System

Project Scope Boundaries

  • 3 Shifts: Morning (6AM-12PM), Afternoon (12PM-6PM), Evening (6PM-10PM).
  • 3 Categories: Coffee/Drinks, Pastries, Heavy Meals.
  • 2 Channels: Cash and GCash.
  • Architecture: Single-page layout running 100% client-side without backend databases.

Proposed BI Solution

  • Integrated point-of-sale cashier entry logger.
  • Instant dynamic Key Performance Indicators (KPIs).
  • Filterable HTML5 Canvas horizontal category bar charts.
  • Automated operational recommendation insight generator.

Data Ingestion & Live Feed

Capturing POS Input and Processing Memory Records

The cashier enters transaction details through our Point-of-Sale form. When logged, JavaScript handles memory storage and UI updates.

1. Append Entry with .push()

transactions.push({ id: Date.now(), timeOfDay, category, paymentMethod, billAmount });

2. Dynamic Table Ledger Rendering

Calls renderTable() to clear and rebuild rows via Vanilla JS DOM manipulation without page reloads.

3. Clean Deletion with .filter()

transactions = transactions.filter(item => item.id !== selectedId);

BI Analytics Engine & KPIs

Calculating Core Performance Metrics in Real Time

1. Total Revenue (₱)

Uses .reduce() to sum all transaction amounts dynamically:

const total = data.reduce((acc, curr) => acc + curr.billAmount, 0);

2. Top Payment Method

Compares Cash vs GCash transaction counts using frequency counter logic.

3. Total Order Volume

Reads array size instantly using data.length.

HTML5 Canvas Visualizations

Framework-Free Bar Graphs Driven by Shift Filters

  • Zero External Chart Libraries: Uses native HTML5 Canvas 2D API for maximum speed and zero dependencies.
  • Shift Filtering via .filter(): Isolates morning, afternoon, or evening records:
const filteredData = activeFilter === "All" ? transactions : transactions.filter(t => t.timeOfDay === activeFilter);
  • Dynamic Proportional Scaling: Aggregates totals, finds max revenue using Math.max(), and draws bar rectangles using ctx.fillRect().
